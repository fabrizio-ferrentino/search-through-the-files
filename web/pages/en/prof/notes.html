NUMERICAL ANALYSIS I - LECTURE NOTES
Chapter 3: Gaussian elimination (version of 03/15/1999)

3.1  The problem

Given a square matrix A (n by n) and a vector b, find x such that
A x = b.  We assume A is non-singular.

3.2  Elimination without pivoting

for k = 1 to n-1
    for i = k+1 to n
        m = a(i,k) / a(k,k)
        for j = k to n
            a(i,j) = a(i,j) - m * a(k,j)
        b(i) = b(i) - m * b(k)

After this, A is upper triangular and we solve by back substitution:

x(n) = b(n) / a(n,n)
for i = n-1 down to 1
    x(i) = ( b(i) - sum of a(i,j) x(j) for j = i+1..n ) / a(i,i)

3.3  Cost

The elimination takes about  (2/3) n^3  floating-point operations.
Back substitution takes about  n^2.  For n = 100 this is about
670000 operations: a few seconds on a good workstation, a minute
or two on a home computer. For n = 1000 do not wait.

3.4  Why pivoting?

Take  A = ( 0.0001  1 )   b = ( 1 )
          ( 1       1 )       ( 2 )

The exact solution is close to x = (1.0001, 0.9999). With four
decimal digits and no pivoting you get x(1) = 0, which is wrong
by 100 per cent. Swap the rows first and the answer is right.
The pivot must not be small compared with the other entries.

3.5  Exercises

(a) Solve by hand the 3 by 3 system on the board. Count the
    operations. Check with the formula above.
(b) Write a program that solves a system read from a file and
    prints the residual.  Try a Hilbert matrix of order 8.
    Explain what you see.

A note on rounding errors

A frequent mistake of beginners is to compare two floating-point numbers for equality. The number 0.1 cannot be represented exactly in binary, so adding 0.1 ten times does not give exactly 1. A program that loops until a variable is equal to 1 may never stop. Compare with a tolerance, and say what the tolerance is.

The same holds for cancellation: subtracting two nearly equal numbers destroys most of the significant digits. The classic example is the solution of the quadratic equation by the textbook formula when one root is much smaller than the other. Use the product of the roots to avoid it.

A story for the curious: in the 1960s a program for a weather model gave different forecasts on two computers that were supposed to be identical, because of a difference in the last digit of one constant. The discussion of that case is in the second hour of lecture 4.
